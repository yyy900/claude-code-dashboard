HOOKS · WRITE-BACK

Add a hook in 20 seconds.

Pick event (UserPromptSubmit, PreToolUse, …), paste bash, save. Panel drops the script into ~/.claude/panel-hooks/ with chmod +x and appends to settings.json — with .panel.bak backup.

Data dominates

Three tables. Twelve modules collapse.

"Permission grant" is an entity. "Setting" is an entity. A session is just a run with no parent. Audit views are SELECT * FROM event WHERE kind = ? with filters.

entity
id · primary key
kind · plugin | skill | hook | setting | permission_grant
name
parent_id · skill belongs to plugin
enabled
config · JSON
Everything you "install" or configure lives here. One table, one toggle column.
run
id
parent_run_id · NULL = session root
entity_id
status · running | success | failed | …
input · output · error
started_at · ended_at
A session is just a run with parent_run_id IS NULL. Children nest underneath.
event
id
run_id
kind · log | permission_request | resource_access | artifact
level · debug | info | warn | error
payload · JSON
Logs, audits, permission decisions, files written — all here, distinguished by kind.

3 tables · 5 indexes · 18 endpoints · 7 tabs in the UI

Quick start

Run it in 30 seconds.

No dependencies. macOS / Linux. Python 3.

$ git clone https://github.com/yyy900/claude-code-dashboard $ cd claude-code-dashboard $ python3 server.py › panel on http://127.0.0.1:7780

Open the URL, click Import from ~/.claude in any of the Plugins / Skills / Hooks tabs. Your real data flows in. The Sessions and Memory tabs read your disk directly — no import needed.
